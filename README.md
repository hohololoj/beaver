# beaver 🦫

Утилита для быстрого поиска файлов и папок в Windows с интеграцией в контекстное меню Проводника.

Работает быстрее встроенного в проводник поиска. После установки добавляет пункт **«Поиск в beaver»** в контекстное меню папок. При вызове путь автоматически подставляется в поле стартовой директории.

## Что умеет 🔧

- Рекурсивный многопоточный сканер по стартовой директории
- Запуск и подстановка начальной директории из открытого проводника (контекстное меню)
- Фильтрация результатов:
  - Исключать по названию.
  - Оставить только по названию.
  - Фильтр по типу все / папка / файл.
- Экспорт результатов: копирование в буфер обмена или сохранение в `search_result.txt`.

## Системные требования 💻
 - Приложение использует прямое чтение MFT для максимальной скорости поиска.
 - Потребление памяти зависит от количества записей в MFT (файлов и папок).
 - **Ориентир**: **~2 ГБ** свободной памяти в пиковый момент сканирования для систем с ~2 млн файлов.
 - Рекомендуется иметь минимум 4 ГБ свободной ОЗУ для стабильной работы системы во время индексации.

## Стек ⚙️

- **Сканер:** C
- **Оболочка:** Neutralino.js
- **Платформа:** Windows

## Требования для сборки 📦

- GCC (MinGW-w64)
- Neutralino CLI (`neu`)
- Resource Hacker
- Inno Setup Compiler (`iscc.exe`)

## Сборка 🔨

Полная сборка проекта:

```bat
build.bat
```

Скрипт компилирует сканер, упаковывает GUI, помещает артефакты в build/ и проводит сборку установщика.

Режим разработки 🛠️
1. Сборка сканера:
```bat
cd bin
./build
```
2. Запуск GUI:
```bat
cd gui
neu run
```

## Использование 🖥️

- ПКМ по свободному месту в проводнике → «Поиск в beaver».
- Ввести строку поиска.
- Нажать «Найти».
- При необходимости применить фильтры.
- Кликнуть по результату для открытия в Проводнике или экспортировать/скопировать список.
