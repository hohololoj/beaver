# beaver 🦫

Утилита для быстрого поиска файлов и папок в Windows с интеграцией в контекстное меню Проводника.

Предназначена для случаев, когда встроенный поиск Windows работает медленно. После установки добавляет пункт **«Поиск в beaver»** в контекстное меню папок. При вызове путь автоматически подставляется в поле стартовой директории.

## Что умеет 🔧

- Рекурсивный поиск по имени (файлы и папки).
- Многопоточный сканер на C.
- Открытие результатов в Проводнике по клику.
- Локальная фильтрация результатов:
  - Исключить (`exclude`).
  - Оставить только (`include`).
  - Фильтр по типу (`all` / `file` / `dir`).
- Экспорт результатов: копирование в буфер обмена или сохранение в `search_result.txt`.

## Стек ⚙️

- **Сканер:** C
- **Оболочка:** Neutralino.js
- **Платформа:** Windows

## Требования для сборки 📦

- GCC (MinGW-w64)
- Neutralino CLI (`neu`)
- Resource Hacker
- Inno Setup Compiler (`iscc.exe`)

## Сборка 🔨

Полная сборка проекта:

```bat
build.bat
```

Скрипт компилирует сканер, упаковывает GUI и помещает артефакты в build/.

Режим разработки 🛠️
1. Сборка сканера:
```bat
cd bin
build.bat
```
2. Запуск GUI:
```bat
cd gui
neu run
```

## Использование 🖥️

- ПКМ по папке в Проводнике → «Поиск в beaver».
- Ввести строку поиска.
- Нажать «Найти».
- При необходимости применить фильтры.
- Кликнуть по результату для открытия в Проводнике или экспортировать список.
